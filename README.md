## 🤖 IA aplicada

- **Agentes de IA** — desenvolvimento assistido por agentes, com planejamento, revisão de código e verificação
- **Orquestração** — múltiplos agentes trabalhando em paralelo em tarefas complementares
- **Skills & MCP** — skills que dão aos agentes o padrão de cada projeto e conexão de modelos a ferramentas externas via Model Context Protocol
- **RAG** — respostas de IA ancoradas em documentos e dados próprios, com mais precisão e menos alucinação
- **Integrações & Automação** — IA conectada a sistemas via APIs e webhooks; automação de fluxos com **n8n**
- **Harness Engineering** — regras de contexto, memória, hooks e travas de segurança no ambiente dos agentes
